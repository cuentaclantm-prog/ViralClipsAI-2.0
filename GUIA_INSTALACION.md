# Guía rápida

Este ZIP contiene el código fuente y la receta de compilación, no el instalador final.

1. Descomprime la carpeta.
2. En Windows instala Python 3.11 de 64 bits desde python.org y marca “Add Python to PATH”.
3. Haz doble clic en `build_windows.bat`.
4. Espera a que termine. La aplicación quedará en `dist\ViralClipsAI\ViralClipsAI.exe`.

Si usas GitHub Actions, sube el contenido de esta carpeta a un repositorio y ejecuta el workflow “Build ViralClipsAI for Windows”. Descarga el artefacto `ViralClipsAI-Windows`.

Si aparece un error, envía una captura del mensaje completo.
